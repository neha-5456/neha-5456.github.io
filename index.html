GENAI / RAG

GenAI Document Chatbot

Chat With Your Documents Using RAG + Vector Search

Problem
Users needed to quickly find specific answers buried in large PDF/DOCX files — manual search was slow and LLMs without context hallucinated answers.
Solution
Built a RAG pipeline: chunk documents with overlap, embed via OpenAI, store in FAISS/ChromaDB, retrieve top-K context, then feed to GPT-4 for grounded answers.
Impact
Sub-second retrieval. Multi-format support. Significantly reduced hallucinations through strict context grounding and source attribution.
RAG Pipeline:
Upload -> Chunk -> Embed -> FAISS Store
Query -> Embed -> Top-K -> GPT-4 -> Answer
LangChainFAISSChromaDBOpenAIDjango
