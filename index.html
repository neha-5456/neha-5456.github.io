GenAI / RAG

GenAI Document Chatbot

Chat With Your Documents Using RAG + Vector Search

Problem
Users needed answers from large PDF/DOCX files — manual search was slow and LLMs without context hallucinated.
Solution
Built RAG pipeline: chunk documents, embed via OpenAI, store in FAISS/ChromaDB, retrieve top-K context, feed to GPT-4 for grounded answers.
Impact
Sub-second retrieval. Multi-format support. Significantly reduced hallucinations through strict context grounding.
RAG Pipeline:
Upload → Chunk → Embed → FAISS Store
Query → Embed → Top-K → GPT-4 → Answer

Anomaly Detection

Fraud Detection Service

Real-Time Credit Card Fraud Screening

Problem
Only 0.2% of transactions are fraudulent — but missing them costs millions. Standard models overwhelmed by 99.8% legitimate data.
Solution
SMOTE oversampling + ensemble of XGBoost (precision) and Isolation Forest (anomaly), with cost-function threshold optimization.
Impact
95%+ recall — catches 19 out of 20 fraud cases. Low-latency API for real-time approve/flag/block.
Pipeline: Transactions → SMOTE → XGBoost + IsolationForest → API = 95%+ Recall
