GenAI / RAG

GenAI Document Chatbot

Chat With Your Documents Using RAG + Vector Search

Problem
Users needed answers from large PDF/DOCX files — manual search was slow and LLMs without context hallucinated.
Solution
RAG pipeline: chunk documents, embed via OpenAI, store in FAISS/ChromaDB, retrieve top-K context, feed to GPT-4 for grounded answers.
Impact
Sub-second retrieval. Multi-format support. Significantly reduced hallucinations via strict context grounding.
RAG Pipeline:
Upload → Chunk → Embed → FAISS Store
Query → Embed → Top-K → GPT-4 → Answer

Fraud Detection Service

Problem
Only 0.2% of transactions fraudulent — missing them costs millions. Standard models overwhelmed by legitimate data.
Solution
SMOTE oversampling + ensemble of XGBoost (precision) and Isolation Forest (anomaly), cost-function threshold optimization.
Impact
95%+ recall — catches 19/20 fraud cases. Low-latency API for real-time approve/flag/block.
Pipeline: Transactions → SMOTE → XGBoost + IsolationForest → 95%+ Recall
